# نادي مصباح — كلية الأعمال | PRD

## Problem Statement (original)
منصة ويب عربية (RTL) لإدارة نادي "مصباح" الطلابي — كلية الأعمال. تجمع الطالبات، إدارة النادي، والدكاترة لإدارة الفعاليات، العضويات، المحتوى، والتواصل.

## Stack
- Frontend: React 19 + TailwindCSS (RTL كامل، خطوط Tajawal/El Messiri)
- Backend: FastAPI (Python) — /app/backend/server.py
- DB: MongoDB (MONGO_URL من env)
- Auth: Passwordless — Email + OTP عبر Resend (Emergent-managed) + JWT httpOnly cookies
- Storage: Emergent Object Storage (ملفات الورش PDF/صور/فيديو)

## User Personas
- طالبة (student)
- دكتورة (supervisor)
- قائدة وحدة الإدارة / القانون / الإعلام / المحاسبة (leader_*)
- نائبة قائدة لكل وحدة (deputy_*)
- إدارة النادي (admin)

## Core Requirements (static)
- تسجيل دخول بالبريد + OTP (بدون كلمة مرور)
- العضو الجديد يدخل مباشرة — حالة "نشط" تلقائياً (لا توجد شاشة انتظار موافقة)
- فعاليات: إنشاء/تسجيل/سعة/حضور/نقاط تلقائية
- ورش الدكاترة: فيديو + PDF + روابط + جدولة
- إعلانات النادي + تعليقات على الفعاليات والورش
- نظام نقاط ومستويات (سراج مبتدئ → قنديل متألق → مصباح ذهبي) + لوحة شرف
- لوحة Admin: إحصائيات، إدارة أدوار، موافقات
- الهوية البصرية = شعار النادي الرسمي حرفياً (أزرق رمادي + تركوازي + أزرق فاتح)، بدون زيادة أو نقصان
